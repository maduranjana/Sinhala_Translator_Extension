# 💬 Madu Sinhala Translator ❤️

**Madu Sinhala Translator** is a browser extension that helps you instantly translate English words to Sinhala. Just highlight or select a word on any webpage, and a popup will show its meaning in Sinhala.

## 🔧 Features
- Quick Sinhala translation by selecting English words
- Interactive popup UI with part-of-speech info (noun, verb, etc.)
- Clean and minimal interface
- Works on most websites
- Includes links to developer's GitHub and LinkedIn

---

## 🚀 Installation

### For Chrome

1. Download or clone this repository.
2. Open Chrome and go to `chrome://extensions/`
3. Turn on **Developer mode** (toggle in the top right).
4. Click **Load unpacked**
5. Select the folder where this extension’s files are located.
6. You will see the extension icon appear in the browser toolbar.

### For Microsoft Edge

1. Download or clone this repository.
2. Open Edge and go to `edge://extensions/`
3. Turn on **Developer mode**
4. Click **Load unpacked**
5. Choose the folder where the extension files are stored.
6. The extension will now appear in the Edge toolbar.
